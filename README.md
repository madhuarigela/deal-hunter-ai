# Deal Hunter AI

An AI-focused deal discovery web application built with a modern React and TypeScript frontend stack.

## Tech stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Getting started

```bash
git clone https://github.com/madhuarigela/deal-hunter-ai.git
cd deal-hunter-ai
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Project focus

The project explores a product/deal discovery experience with a modern, responsive interface.
